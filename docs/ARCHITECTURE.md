# Архитектура

Менеджер владеет переходами STA/AP, но использует только один экземпляр
`wpa_supplicant`. AP поднимается отдельным конфигом через контролируемый
перезапуск, а возврат в STA подтверждается состоянием `COMPLETED` и IPv4.

Сохранённые профили хранятся в:

```text
/bkupgrade/data/wpa_supplicant.conf
```

`.bak` содержит последнюю подтверждённую версию. Чтение конфигурации не должно
перезаписывать `.bak`; это важно, потому что runtime `wpa_supplicant` может
временно записать устаревшие данные.

Во время AP `maind --platformd` и `dhcpcd` замораживаются единым
`ProcessGuard` и размораживаются только для PID, остановленных этим guard.
