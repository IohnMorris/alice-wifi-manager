# Security policy

## Supported versions

Only versions explicitly marked as tested on a real Yandex Station Mini 2 are
considered supported.

## Reporting

Do not publish Wi-Fi passwords, device logs containing credentials, private
keys, or complete production configurations in an issue. Report security
problems privately to the repository owner before public disclosure.

## Sensitive data

The manager must never write Wi-Fi passwords to diagnostic logs. Device
configuration files and runtime logs must remain outside source control.
